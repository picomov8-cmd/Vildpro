# VILD Pro

مخزن مرجع پروژه استراتژی معاملاتی **VILD Pro 0.1**.

## سند اصلی پروژه

- [سند مادر VILD Pro 0.1](docs/VILD-Pro-0.1.md) — هدف، تنظیمات تأییدشده، قوانین اولیه، تاریخچه تصمیم‌ها، الزامات Pine Script v6، پروتکل بک‌تست و موارد باز.

## وضعیت فعلی

- نماد: XAUUSD
- پلتفرم: TradingView
- زبان: Pine Script v6
- سبک: Scalping با رویکرد SMC / ICT و نقدینگی
- تایم‌فریم اجرای موردنظر: M1
- وضعیت: تدوین و تکمیل قوانین مکانیکی پیش از پیاده‌سازی و بک‌تست

**اصل مهم:** تنظیمات تأییدشده بدون اجازه کاربر تغییر نمی‌کنند. موارد ناقص در سند اصلی به‌عنوان موارد باز مشخص شده‌اند و نباید با حدس تکمیل شوند.
